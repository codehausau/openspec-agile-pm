# Product Documentation

This catalog contains approved product requirements and capability documentation
published by the `agile-pm` archive workflow. Each change-namespaced directory is
a byte-for-byte copy of an approved PRD set and includes its approval record.

These documents describe approved product intent, user outcomes, priorities, and
boundaries. They are not OpenSpec normative specifications, release notes, or by
themselves proof that behavior is available in a deployed version.

The archived files under `openspec/changes/archive/` remain the approval record.
Do not edit published snapshots or generated catalog rows directly. Correct or
supersede product documentation through a new approved `agile-pm` change.
